## 가드 기준으로 고친 것 (분석 보고서 6장)

- 뺀 말: "티타늄을 하면 일단 얼굴이 작아보여요 … 가장 추천되는 이유입니다"(효과 단정, ④). 2주 전 단락은 "티타늄을 가장 강력하게 추천드리고 싶습니다"에서 끝냅니다.
- 처방약 제품명(⑦): 말은 "스킨 보톡스"지만 자막은 "스킨 톡신". 톡신 제품 사진은 넣지 않았습니다.
- 가격·전후 사진·타 병원 비교·연예인 없음.
- 말에 "가장 추천"이 두 번 남아 있습니다(원장 의견 화법). 더 보수적으로 가려면 해당 구를 잘라야 합니다.
