## 반영하지 않은 것

- 리뷰에서 대본집대로 1.5초마다 컷과 순간 줌을 넣으라는 지적이 있었지만, 얼굴이 흔들린다는 요청에 따라 넣지 않았습니다.
- 소리로는 '가장 추천'이 두 번 남아 있습니다(원장 의견 화법). 더 보수적으로 가려면 해당 구를 잘라야 합니다.
- 길이 53.6초는 보고서 기준(25~35초)보다 깁니다. 줄이려면 '한 달 전' 단락(32.4초~)부터 따로 떼어 두 편으로 나누는 방법이 있습니다.
- 원장 오른쪽 눈 밑의 노란 자국(원본에 있음)은 출연자 얼굴 보정이라 승인을 받은 뒤에만 처리합니다.
- 가슴의 무선 마이크 로고(dji)는 촬영본에 그대로 보입니다.

## 다시 만들기 (`build/`)

1. `prep.py <작업폴더> 이름=DriveID ...` : 다운로드, 받아쓰기(단어 시각), 쉼 지점, 프레임 시트
2. `cut.py plan_jm.json` : 구간을 자르고 0.22초 넘는 쉼을 걷어 냄. 컷마다 얼굴을 고정하고 HLG를 BT.709로 톤매핑. 결과는 `<out>.json`(컷 목록)
3. `shotface.py <컷.mov> <컷.json> 1084 > shotoff.json` : 컷별 자막·그래픽 내림 값. `overlay5.html`의 `SHOTOFF`에 넣음
4. `render2.cjs`(`OV=overlay5.html OD=ov node render2.cjs full 53.61`) : 오버레이 PNG를 30fps로. 글꼴은 `~/.fonts`의 Do Hyeon, Pretendard. 이미지는 `assets/`
5. `qa.py <컷.mov> ov` : 얼굴 가림과 UI 영역 검사
6. ffmpeg 합성: overlay → loudnorm -14 LUFS → libx264 BT.709 태그
