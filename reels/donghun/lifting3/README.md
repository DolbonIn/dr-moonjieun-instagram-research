## 왜 두 원장이 나오나

쎄르프 설명이 "마지막은 쎄르프입니다", "오늘 나온 세 가지 시술", "첫 번째, 두 번째 온다 티타늄"으로 온다·티타늄 소개를 전제로 합니다. 이동훈 원장의 온다·티타늄 원본(`20261002_210339`, `210545`, `211350`, `211444`, `211811`)은 Drive 공유가 아직 '링크가 있는 모든 사용자'가 아니어서 받을 수 없습니다. 그래서 받은 영상 중 온다·티타늄을 설명한 이재민 원장 본 테이크(`20261002_213221`)에서 해당 구간을 가져왔습니다. 이동훈 원장 원본이 열리면 1·2번 구간만 바꿔 끼우면 됩니다.

## 화면 검사

- 가슴의 무선 마이크(dji 로고)는 흐림 처리를 시험했지만 회색 얼룩처럼 보여 원래대로 두었습니다. 참고 계정 릴스도 마이크를 그대로 보입니다. 삽입 그래픽이 아니라 촬영 장비라 가드의 타사 로고 기준에 해당하지 않는다고 판단했습니다.
- 이재민 원장 눈 밑의 노란 자국은 출연자 보정이라 승인 전에는 손대지 않았습니다.

- 얼굴: 컷마다 얼굴을 10fps로 찾아, 턱 아래 70px까지 비도록 자막·그래픽을 컷 단위로 내렸습니다(최대 28px). 954프레임 모두 얼굴 겹침 0, 하단 UI 0, 오른쪽 버튼 0입니다.
- 제목·소제목과 머리카락 사이는 최소 50px입니다.
- 소파 쿠션 로고 흐림은 이동훈 원장 구간(7.68초~)에만 걸었습니다.
